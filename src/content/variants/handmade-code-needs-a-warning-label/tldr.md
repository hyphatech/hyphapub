1. A demand for an AI disclosure says nothing about the actual work.
2. Calculating by hand was respected work once, yet today nobody would brag about a week spent on an equation a computer solves in a few seconds.
3. Meticulously handcrafted software is heading the same way.
4. Deliberate work with agents can now reach the same bar in a fraction of the time, which is what the globally accelerating market enforces.
5. Agents hold far more of a system in view than anyone can keep up for long.
6. They quick-test dozens of assumptions and ask the language server and the profiler instead of going on a hunch.
7. With [Hypha Stack](https://hyphatech.io/stack), most decisions are taken before a model writes a line, and everything after is held by enforced boundaries, the shared ontology, gates no one can skip and validation against the agreed scenarios.
8. "AI slop" exists, and so does the handmade kind, known as "shitcode".
9. Writing off a whole body of work for the tools behind it is an idiotic prejudice, with the blast radius of any other.
10. I believe it grows in communities that pay for visible effort in stars and respect, whose currency an agent makes worth less by delivering the same quality with less labour.
11. What I need is a solved problem, a working result I can trust, and I couldn't care less how it was done.
12. I find it reasonable to demand a "HANDMADE" label, so everyone knows up front the code runs on someone's hunches.
